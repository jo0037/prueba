Archivos de trafico de datos:

Para leer los datos que el computador ha estado enviando, se necesita usar la herramienta Wireshark. El procedimiento para leer la captura de trafico (https), mediante el registro de llaves ssl se puede ver en youtube. La captura de trafico pcap que se intercepto durante los primeros 30 minutos de encendido del computador se puede descargar con el boton "Descargar SSL Key Log File". Las llaves ssl usadas se pueden descargar con el boton "Descargar Trafico Capturado".
